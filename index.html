The same applicant, evaluated on two dates. Rules carry effective and expiry dates, so a policy change never rewrites history. The U.S. terminated its Syria sanctions program effective July 1, 2025, so OFAC-001 has a version before that date and a version after it.

Rules live as data, not code. Each one carries a version, dates, and the regulation it implements. Pick a date to see which versions are in force.
